# 🏥 Hospital Appointment Booking System – Backend

## Final Year Project  
**Department of Computer Science**  
**Academic Year:** 2024–2025  

---

## 📖 Project Overview
The Hospital Appointment Booking System is a web-based application designed to automate and manage hospital appointment scheduling.  
It provides a centralized platform for **Admin**, **Doctor**, and **Patient** roles to efficiently handle appointments, reduce waiting time, and eliminate manual paperwork.

---

## 🎯 Objectives
- Automate hospital appointment scheduling
- Reduce patient waiting time
- Improve hospital workflow efficiency
- Provide secure and reliable data management
- Eliminate manual and paper-based processes

---

## 👥 System Users
### Admin
- Manage doctors and departments
- View all appointments

### Doctor
- View assigned patient appointments

### Patient
- Register and manage appointments
- View doctors and book appointments

---

## 🏗️ System Architecture
- **Frontend:** Angular (UI)
- **Communication:** REST APIs
- **Backend:** Java Spring Boot
- **Database:** H2 (In-Memory)
- **API Documentation:** Swagger UI

---
